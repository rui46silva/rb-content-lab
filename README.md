# RB Content Lab — Estratégia & Blueprint do Website

Repositório de estratégia, conteúdo e orientação técnica para o desenvolvimento do
site institucional da **RB Content Lab** em WordPress.

> **Objetivo do site:** não é um portefólio bonito — é uma máquina de conversão de
> visitantes em clientes de alto ticket. Cada secção existe para gerar prova,
> autoridade ou ação.

## Princípios não-negociáveis

1. **Conversão acima de decoração.** Cada página tem *um* objetivo primário e *uma*
   ação principal. Se uma secção não move o visitante para essa ação, corta-se.
2. **Prova antes de promessa.** Resultados, números e nomes de clientes vêm à frente
   de adjetivos. "Aumentámos o pipeline em 3x" bate "somos criativos".
3. **Estética com assinatura.** Nada de templates genéricos. Tipografia editorial,
   paleta própria, layouts assimétricos com intenção.
4. **Performance é feature comercial.** Site lento = cliente premium perdido.
   Meta: Lighthouse 90+ em Performance, SEO, Best Practices e Accessibility.
